# 📄 Resume – Rehan Ali

A personal resume website built with **HTML** and **CSS**, hosted on **GitHub Pages**.

🔗 **Live Demo:** [09rehanali.github.io/Resume](https://09rehanali.github.io/Resume/)

## ✨ Features

- Clean, simple, and easy-to-read layout
- Fully static, with no frameworks or dependencies
- Lightweight and fast to load
- Easy to customize with your own details
- Free hosting through GitHub Pages

## 🛠️ Built With

- **HTML5**: page structure and content
- **CSS3**: styling and layout

## 🚀 Getting Started

### Run locally

1. Clone the repository
   ```bash
   git clone https://github.com/09RehanAli/Resume.git
   ```
2. Go into the project folder
   ```bash
   cd Resume
   ```
3. Open `index.html` in your browser. No build step is needed.

### Use it as your own template

1. Fork this repository
2. Edit `index.html` with your own name, skills, education, experience, and contact details
3. Adjust colors, fonts, and spacing in `style.css`
4. Replace `Demo.jpg` with a screenshot of your own version

### Deploy on GitHub Pages

1. Push your changes to the `main` branch
2. Go to **Settings → Pages**
3. Under **Source**, choose the `main` branch and the `/ (root)` folder
4. Save, and your site will be live at `https://<your-username>.github.io/Resume/`
