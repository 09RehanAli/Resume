## 🚀 Getting Started

### Run locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/09rehanali/Resume.git
   ```
2. **Navigate into the folder**
   ```bash
   cd Resume
   ```
3. **Open the page**
   Open `index.html` in your browser, or use the VS Code _Live Server_ extension.

### Deploy on GitHub Pages

1. Push the code to your GitHub repository.
2. Go to **Settings → Pages**.
3. Under **Source**, select the `main` branch and the `/ (root)` folder.
4. Save, and your site will be live at `https://<username>.github.io/Resume/`.
